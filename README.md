Yiran Dance Website
====================

This is a cinematic, dark-themed portfolio website for a dancer and movement artist.

## Structure

- `index.html` — About (landing) page
- `choreography.html` — Choreography work
- `dance-film.html` — Dance film page with embedded video
- `modeling.html` — Modeling portfolio
- `acting.html` — Acting and performance work
- `styles.css` — Shared styling for all pages

## How to view

Open any of the `.html` files directly in a browser (for example, drag `index.html` into Chrome or Safari).

## Customize

- Update social links in the footer of each `.html` file.
- Replace placeholder text with your own biography and project descriptions.
